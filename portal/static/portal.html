Master Architecture Reference: Gotchas, Patterns & Anti-Patterns

Regulatory and operational guardrails for running biopharma agent swarms across cloud boundaries.

1. Cross-Cloud Network Egress
Pattern: Dedicated Cross-Cloud Interconnect (CCI) / AWS PrivateLink to GCP PSC. Zero internet gateways.
Anti-Pattern: Public internet NAT Gateway with static IP whitelisting. Violates HIPAA and exposes endpoints to DDoS.
Gotcha: MTU 1440 on GCP vs 1500 on AWS causes silent TCP fragmentation drops if MSS clamping is omitted.
2. Identity & Authentication
Pattern: Keyless Workload Identity Federation (WIF) exchanging AWS SigV4 STS tokens for short-lived GCP tokens.
Anti-Pattern: Storing long-lived Google Service Account JSON keys (`sa-key.json`) in AWS Secrets Manager.
Gotcha: Clock drift > 5 minutes between AWS and GCP hypervisors causes immediate rejection of STS assertions.
3. Clinical Data Residency
Pattern: Compute-to-Data In-Situ: Leave CDISC SDTM records inside GCP BigQuery; only transmit sanitized variances.
Anti-Pattern: Replicating clinical tables into an external cloud data lake. Breaches GDPR and data sovereignty contracts.
Gotcha: Multi-region BigQuery queries cross perimeter boundaries unless restricted to specific single-region datasets.
4. Sub-28 µs AST Sanitization
Pattern: Zero-copy in-memory recursive dictionary stripping with pre-allocated O(1) hash sets.
Anti-Pattern: Regular expression string parsing (`re.sub`) on payload JSON string. Causes ReDoS thread exhaustion.
Gotcha: Deep circular dictionary references crash standard recursive filters; always bound recursion depth to 20 levels.
5. Stateless HITL Tokens
Pattern: 48-hour HMAC-SHA256 tokens signed with Cloud KMS HSM. No relational database write locks.
Anti-Pattern: Database tables holding `PENDING_APPROVAL` row locks during physician review (24-48h).
Gotcha: Token replay attack: Without JTI nonce caching, an approved token can be replayed repeatedly.
6. FDA 21 CFR Part 11 Rule
Pattern: Mandatory physician human intent verification clause before modifying clinical trial dosing.
Anti-Pattern: "Full-Auto" autonomous AI agent execution altering patient dosing without human clinician signature.
Gotcha: Storing electronic signatures without UTC ISO-8601 timestamps and full signer role invalidates FDA audits.
